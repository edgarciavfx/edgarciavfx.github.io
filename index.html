Artist & Engineer

I'm a VFX compositor and software developer — a hybrid who bridges artistry with engineering.

It started with a Stalingrad breakdown. Watching set extensions, keying, and explosions composited together in Nuke clicked something in me. That curiosity took me from Guadalajara to Vancouver Film School, then into production — shipping VFX for MPC, Ingenuity Studios, La Covacha, and beyond.

Over 6+ years in production, I've been the artist staring at a slow workflow. So I learned to build the fix. Now I create desktop utilities, pipeline tools, and web applications that reduce friction for the artists on the other side.

Artist First

I've been in the chair. I know what slows a compositor down, what breaks in a render, what a bad pipeline feels like. Every tool I build starts from that perspective.

Bridging Worlds

Featured Projects

WORKFLOW // 01

Plate

A desktop and CLI utility for VFX and AI artists that collapses a multi-step Nuke workflow into one focused tool: load a video plate, scrub the timeline with draggable handles, set IN/OUT points, and export a production-ready shot folder. Handles proxy generation with burn-ins, LUT/OCIO color transforms, Nuke script generation, and background batch rendering via a shot queue.

Python PySide6 FFmpeg FFprobe OpenColorIO
[IN] Video plate + IN/OUT frame range
[OUT] EXR sequence + H.264 proxy + manifest.json

WORKFLOW // 02

Flipbook

A local-first review tool for compositing work, organized hierarchically — Project → Shot → Version → frame. Delivers frame-accurate playback and frame-by-frame stepping without browser seek artifacts, drawn and text annotations anchored to specific frames, status tracking (WIP → Needs Review → Approved), and one-click jumps back to the source Nuke script. Everything stays on disk — nothing is uploaded.

Next.js React TypeScript SQLite Drizzle Tailwind Radix UI FFmpeg
[IN] Shot versions (.mov / EXR / DPX) + Nuke Write metadata
[OUT] Frame-accurate playback + annotations + review status
View on GitHub
WORKFLOW // 03

comfy-watch

A terminal tool to watch Claude drive ComfyUI Cloud live over MCP. Connects to the Comfy Cloud WebSocket and prints a plain-line log of execution events — queue, node progression, progress %, done/error — while auto-opening the workflow graph in the browser. A --save flag captures denoising preview frames, and --raw dumps unfiltered frames for protocol debugging.

Python WebSocket MCP ComfyUI Cloud
[IN] Comfy Cloud WebSocket URL (clientId + token)
[OUT] Live terminal execution log + saved preview frames
